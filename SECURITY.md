# Security policy

Report suspected vulnerabilities privately using GitHub's **Report a vulnerability**
action in the repository's **Security** tab, when enabled. Otherwise contact the
maintainer privately. Include the affected version, the impact and enough information
to reproduce the issue without sharing credentials or private project files.

Run `executor-queue` only in a checkout and under a user account you trust. Keep
the ledger, review exports and bridge state local. Review what each external
executor would receive before submitting work. See [What gets shared in the README](README.md#what-gets-shared).
