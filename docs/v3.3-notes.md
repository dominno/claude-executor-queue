# v3.3.0

The installable skill lives in `skills/executor-queue/`. Skills CLI and the
offline installers ship the same three files, including the MIT license.
Existing offline installations with a clean receipt can upgrade in place.

## Publication checklist

1. Run the Python suite and the Skills CLI smoke test with a fresh user profile.
2. Review the branch, tags, and history intended for public release for private
   metadata, internal paths, sensitive files and credentials. Inspect filenames
   and redact findings in shared logs. Review author email visibility as well.
3. After making the repository public, test
   `npx skills add dominno/claude-executor-queue --skill executor-queue -a claude-code`
   from a clean project without Git credentials. Open a new Claude Code session,
   invoke `/executor-queue` and confirm that it resolves the project-local script.
4. Tag the reviewed release if using Git tags for distribution.

`disable-model-invocation` is a Claude Code frontmatter extension. The Skills
CLI supports this package on Claude Code. Generic validators that disallow
host-specific keys may reject that field.
