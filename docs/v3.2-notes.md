Freshly replayed N1–N7 regressions against v3.1.0 (`603e876`) in an isolated
temporary copy: **19 failed**, including the delegate guard case. N9 threshold cases
and the additional delegate bypass cases were observed failing before their fixes.
Existing guard assertions remain intact; the linked-worktree regression now also
asserts refusal without an explicit default and checks config-based selection.
Old synthetic cloud lifecycle fixtures now append assignment
events directly, since the public assign command correctly refuses that executor.
Installer/version assertions follow 3.2.0; the upgrade fixture advances to 3.2.1.
Existing idle-hook tests inject healthy host readings, preserving their original
assertions independently of host load or sandbox process visibility. The Stop hook
remains read-only and takes no ledger lock. Preflight is a point-in-time check, not
a launch reservation; the lead must serialize concurrent launch decisions. Windows
probes/fallback are covered with injected readings, not a native Windows run.

Validation: `/usr/local/bin/pytest -q tests` — **286 passed, 1 skipped** in
233.36 seconds. The skipped test requires native PowerShell and the Windows launcher.
