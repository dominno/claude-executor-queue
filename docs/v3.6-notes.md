# v3.6.0

`xq status` reads the ledger for the current repository. Use `--id`, `--executor`
and `--state` to select records. `--json` provides a versioned result for scripts.
Read [Task status and refresh](job-status.md) for fields, exit codes and examples.

`xq poll --id <id>` or `xq poll --executor codex|agy` narrows the explicit refresh
to registered tasks. Bare `poll` still checks Codex and imports local agy results.
Cloud observations come from published reports fetched by `cloud-collect`.

The ledger still uses the existing append-only JSONL format. An older xq helper
may ignore new observation events or fields, so update the helpers used by all
sessions sharing the ledger when adopting the new status view. The Skills CLI and
offline installers keep the same three-file package and `scripts/xq.py` entry point.

For publication checks, see [the release checklist](v3.5-notes.md#publication-checklist).
